# Lekha landing site - design

**Date:** 2026-06-16
**Status:** Built. This doc reflects the site as shipped in `site/`.

## Goal

A simple, clean, GitHub Pages landing site for Lekha that shows a visitor what
the app is, how it looks, and how it works - then gets them to download or
`brew install`. One scrolling page, screenshot-led, no framework, no build step.

## Hosting & deployment

- Static files live in a top-level `site/` folder, served by GitHub Pages.
- A GitHub Actions workflow (`.github/workflows/pages.yml`) publishes `site/` on
  every push to `main`, using `actions/configure-pages`, `upload-pages-artifact`,
  and `deploy-pages`. Pages must be set to "GitHub Actions" source once in repo
  settings (manual, one-time).
- The site is served at `https://mocarram.github.io/Lekha/`. All asset and
  internal links are **relative** (e.g. `assets/...`, not `/assets/...`) so they
  resolve under the `/Lekha/` path prefix.
- No framework, no bundler, no npm dependency. Plain HTML + CSS + a few lines of
  vanilla JS. GitHub Pages serves the files as-is.

## File structure

```
site/
  index.html                  one page, all sections
  styles.css                  all styling (brand tokens, layout, responsive, dark)
  main.js                     copy-to-clipboard for the brew commands
  assets/
    icon.svg                  copied from assets/icon/icon-master.svg
    favicon.svg               copied from assets/icon/icon-small.svg
    screenshots/
      primary.png             hero / editor in action (midnight theme)
      sidebar.png             sidebar, folders & tabs (midnight)
      math.png                math & diagrams (midnight)
      window-color-teal.png   window colors - window A
      window-color-amber.png  window colors - window B
      theme-<id>.png          nine theme corner crops for the themes fan:
                              github, sepia, solarized-light, nord,
                              solarized-dark, night, graphite, midnight,
                              high-contrast
```

GitHub Pages cannot reach outside `site/`, so the SVGs and screenshots are
**copied** into `site/assets/` and committed there. The screenshots are
regenerated by the capture spec (below) and copied in.

## Screenshots

Captured, fully reproducible, zero personal data:

- **Source workspace:** `tests/e2e/fixtures/site-workspace/` (a synthetic
  "Field Notes" notebook: Getting Started, Markdown Reference, Math & Diagrams,
  Roadmap, and a Topics/ subfolder). Committed.
- **Capture spec:** `tests/e2e/siteScreenshots.spec.ts` drives the **built** app
  with an isolated `--user-data-dir` per shot, seeding theme / open tabs /
  window color / window bounds via `settings.json`. Output:
  `tests/e2e/screenshots/site/` at 2x retina (that dir is gitignored; the served
  copies under `site/assets/screenshots/` are what ship).
- **Regenerate:** `npm run build && npx playwright test siteScreenshots`, then
  copy the PNGs into `site/assets/screenshots/`.
- **Theme:** the main shots (primary, sidebar, math, window colors) use the
  **midnight** theme - the app's default (see "App change" below). The themes
  section captures all nine themes, each cropped to the top-left corner
  (sidebar + heading), where a theme's palette reads clearest.
- **Traffic lights:** Playwright captures only the web contents, so the capture
  injects macOS traffic-light dots at the window's reserved position
  (`trafficLightPosition { x: 16, y: 15 }`) before each shot. The dots are baked
  into the PNG, so each reads as a real Lekha window.

On the page, each full screenshot sits in a rounded, shadowed "window" card; the
nine theme tiles are cropped corners arranged in a diagonal fan.

## Page sections (top to bottom)

1. **Hero** - navy band (`#171e30`) matching the icon. Centered: the icon tile,
   the "Lekha" wordmark, the tagline "A clean, distraction-free WYSIWYG Markdown
   editor for macOS", a primary **Download for macOS** button, a copy-on-click
   `brew install --cask mocarram/tap/lekha` chip (the fully-qualified token so
   the single command works without a separate `brew tap`), and a GitHub link.
2. **Primary screenshot** - `primary.png` (midnight), full width, framed,
   directly under the hero; the dark window blends into the navy band.
3. **Feature rows** - three alternating image/text rows (image side flips each
   row):
   - **Sidebar, folders & tabs** (`sidebar.png`) - open a folder, browse the
     tree, work across tabs.
   - **Math & diagrams** (`math.png`) - KaTeX formulas and Mermaid diagrams
     render live, inline.
   - **Window colors** - the two windows (`window-color-teal/amber.png`) stacked
     full-width, each cropped to its top with a bold colored top edge, so the
     "tint each project window" idea reads at a glance.
4. **Themes showcase** - a full-width section: heading + the nine theme corner
   tiles arranged as a compact diagonal fan (each offset down-and-right; the
   front tile shown in full, the rest peeking their top-left). Light to dark.
5. **More features** - a compact grid (no screenshots): Find & replace, Focus &
   typewriter modes, Source view, Export & copy, Quick open (`Cmd+P`), Tables &
   task lists.
6. **Install** - the two brew lines (`brew tap mocarram/tap`,
   `brew install --cask lekha`) in a copyable block, plus a "Download the .dmg"
   link to the latest release and a one-line macOS requirement note (macOS 11
   Big Sur or later; unsigned for now, with the right-click-Open first-launch
   note).
7. **Footer** - MIT license, and links: GitHub, Releases, Issues.

## Visual design

- **Brand tokens:** navy `#171e30` (hero/footer), purple `#6e5ef0` (primary
  button, accents, links), light page background for body sections, ink/quote
  grays matching the app.
- **Type:** system font stack (`-apple-system, BlinkMacSystemFont, "Segoe UI",
Roboto, sans-serif`); no web-font dependency.
- **Layout:** centered max-width column (~960px) for text/feature rows; the hero,
  themes showcase, and footer bands run full width with content centered.
- **Responsive:** feature rows stack vertically on narrow screens; the window
  pair stacks; the themes fan uses wider tiles and gentler drift on mobile.
  Fluid down to ~360px.
- **Dark mode:** `prefers-color-scheme: dark` darkens the light body sections
  (the hero/footer are already dark). No toggle; follow the OS.

## Interactions (vanilla JS only)

- **Copy brew command:** clicking the hero chip or the install code block copies
  its text via `navigator.clipboard.writeText` with a brief "Copied" highlight.
  Progressive enhancement - the text is selectable without JS.
- **Download button:** links to `https://github.com/mocarram/Lekha/releases/latest`
  (always current; no hardcoded version in the markup).
- No analytics, no trackers, no cookies, no consent banner.

## App change

To make the screenshots and the default experience consistent, the app's default
theme was changed to **midnight** (`src/main/settings.ts`). This affects only
fresh installs (no existing `settings.json`); users keep any theme they have
chosen. The unit assertion in `tests/unit/themes/settingsTheme.test.ts` was
updated to match.

## Accessibility

- Semantic landmarks (`header`, `main`, `section`, `footer`), one `h1` (the
  hero), logical heading order, `alt` text on every screenshot, visible focus
  styles, and AA contrast in both light and dark.

## Out of scope (v1)

- Blog, changelog page, docs site, search.
- Custom domain (stays on `github.io`; easy to add later).
- Analytics / telemetry.
- Localization.
