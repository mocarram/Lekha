# Markdown reference

A quick reminder of the syntax Lekha understands. You rarely need to look it
up - most of it just happens as you type.

## Text

- **Bold** with `**double asterisks**`
- _Italic_ with `*single asterisks*`
- ~~Strikethrough~~ with `~~tildes~~`
- `Inline code` with backticks
- Footnotes[^1] for asides

## Structure

1. Ordered lists number themselves
2. Nested items indent cleanly
   - Mixed bullet underneath
3. Back to the top level

> Block quotes are great for callouts and pulled-in references.

## Links and tasks

Drop a [link](https://example.com) anywhere, and track work with task lists:

- [x] Learn the basics
- [ ] Build the habit

[^1]: Footnotes collect at the bottom and link back to where you left off.
